Set an event rule's schedule (browser)

Logs in (directly to a server, or via a cloud account), lists the site's event rules over GET /rest/v4/events/rules, and sets the schedule on one or more selected rules with a PATCH /rest/v4/events/rules/{id} per rule — entirely in the browser. The v4 schedule is a structured array of {dayOfWeek, startTime, endTime} tasks; an empty array means "always enabled". All calls go through a local same-origin proxy.

Pick the days and the time window, tick one or more rules above, then click Set schedule on selected rules. Each selected rule gets its own PATCH /rest/v4/events/rules/{id} with one task per chosen day. (No days at all means the schedule can't be built — to make a rule "always enabled," that's a separate empty-schedule case.)

Credentials and the bearer token are sent only to your local proxy, which forwards each call same-origin to the server or the site relay (re-attaching the bearer and re-sending the PATCH body across the relay's 307). This page is a sample, not a production login.
