Copy Device Agent settings to another device

REST v4, GET and PUT /rest/v4/analytics/engines/{engineId}/deviceAgents/{deviceId}/settings, against the configured server through this page's dev proxy.

Sign in

A server account with Power User or better, for both the source and target devices. This page logs in again immediately before each call below.

Download

Downloads one device's Device Agent settings as a JSON file.

Apply

This replaces the target device's existing Device Agent settings. Choose a settings file downloaded above, then type the target device ID to confirm. One device per apply action, by design: to copy the same settings onto more devices, apply again with a different target.
