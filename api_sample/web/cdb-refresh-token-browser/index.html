Refresh-token session (browser)

Logs in to Nx Cloud once, stores the access + refresh tokens in this tab, then renews the session over /cdb/oauth2/token without re-sending the password. Reload the page — the session resumes from sessionStorage.

Security: this sample stores tokens in sessionStorage only to demonstrate the refresh flow. Tokens in the browser are exposed to XSS. sessionStorage is per-tab and cleared when the tab closes. A real app should prefer short-lived in-memory tokens plus an httpOnly-cookie / backend pattern — see the README.
