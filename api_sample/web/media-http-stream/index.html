Play camera video (browser)

Logs in (directly to a media server, or via a cloud account) and plays a camera's live or archive video in an HTML5 <video> tag over /rest/v4/devices/{id}/media.webm — entirely in the browser. The token is sent only to your local proxy, which converts it to a bearer header so it never reaches Nx as a URL parameter.

Credentials and the token are sent only to your local proxy. The proxy turns the ?auth=<token> on the <video> URL into an Authorization: Bearer header before forwarding, so the token never reaches Nx as a URL parameter. This page is a sample, not a production login. For lower-latency live video, see the webrtc-live-view sample.
