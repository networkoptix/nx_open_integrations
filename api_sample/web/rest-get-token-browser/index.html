Get a token — mediaserver (browser)

The smallest possible authentication demo: get a bearer token from one Nx mediaserver, use it, hand it back, then prove it stopped working. No cameras, no events — just the session. The server's address is configured when you start the dev server; enter your local login below.

  1. Get a token — POST /rest/v4/login/sessions
  2. Use the token — GET /rest/v4/login/sessions/current
  3. Revoke the token — DELETE /rest/v4/login/sessions/current
  4. Prove it is dead — the same GET again, which should now be rejected
FieldValue

The token travels in an Authorization: Bearer header. Note that this page hands that header to the local proxy, which is what actually calls the mediaserver — a browser cannot reach a self-signed lab server directly. Credentials are never stored. This page is a sample, not a production login.
