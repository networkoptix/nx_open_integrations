Get an OAuth2 token (browser)

The smallest authentication example: log in to Nx Cloud and show the bearer token — entirely in the browser. Put it in an Authorization: Bearer <token> header on any later CDB or site request.

access_token

Use it on later requests as a header: Authorization: Bearer <token>. The token starts with nxcdb-.

Credentials are sent only to your local proxy (which forwards them to Nx Cloud) and are never stored. This page is a sample, not a production login.
