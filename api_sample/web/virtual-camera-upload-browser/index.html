Create a virtual camera & upload footage (browser)

Creates a virtual camera on one Nx VMS server and uploads a chosen video file into its archive as recorded footage, over /rest/v4 — entirely in the browser. Calls go through the bundled dev proxy (same-origin, self-signed TLS accepted).

    Credentials and the file are sent only to your local proxy, which forwards them to the Nx server you entered; nothing is stored. This page is a sample, not a production tool. A real ingest needs a live server — the offline tests cover the request flow, not the actual media import.
