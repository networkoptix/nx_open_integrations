Event log — cloud user (browser)

Logs in to Nx Cloud and reads one site's recent events from /rest/v4/events/log. Run node server.mjs first (see the README). Step 1: connect. Step 2: pick a window/type and load.

Time (UTC)EventActionResource

Login and the event-log read go through your local proxy (browser CORS rule); the proxy forwards them to Nx Cloud and your site's relay. Credentials are never stored.
