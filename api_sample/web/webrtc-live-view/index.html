Live view — WebRTC (browser)

Logs in to Nx Cloud, lists your site's cameras, and plays one camera's live video in the browser using Network Optix's WebRTC stream manager. Run node server.mjs first (see the README).

The camera list and login go through your local proxy (browser CORS rule). The live video itself connects straight to the site's relay over WebRTC, which is not subject to CORS. Credentials are never stored.
