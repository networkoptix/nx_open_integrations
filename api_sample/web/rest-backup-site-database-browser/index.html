Back up and restore the Site database

REST v4, GET and POST /rest/v4/site/database, against (loading...) through this page's dev proxy.

Sign in

A local administrator account on the server. Both calls require an administrator on a fresh session, so this page logs in again immediately before each one.

Back up

Downloads the whole Site database as an opaque binary file. Note that the browser holds the entire dump in memory before saving it; the Python, Node.js and TypeScript versions stream it to disk instead.

Restore

This replaces the entire site configuration and restarts the server. Servers, cameras, users, groups, layouts, rules, licences and storage settings are all overwritten by the dump.
